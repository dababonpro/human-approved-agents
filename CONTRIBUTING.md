# Contributing

Corrections and evidence are the most useful contributions.

- **Found an error?** Open an issue with the claim, the source and the page.
- **Have evidence?** Say what kind it is: law, standard, guidance, study, vendor data or experience. `playbook/evidence.md` grades claims by that.
- **Changing a skill or template?** Say what it fixes, and what you tested it on.

Keep the writing plain, and in your own words. Quote sources briefly, and link them.

Do not include real company names, staff, customer data or secrets, including in examples and test output.

Pull requests must pass the checks in `.github/workflows/checks.yml`. Read `AGENTS.md` if an agent is helping you.
